# 行者之书

将 PDF 放在这个目录，提交到部署分支后，Jekyll 会自动把它加入 `/life/#walkers-books`，显示在生活页“阅读 📚”下方。无需创建 Markdown 文章或单独阅读页，支持子目录。没有 PDF 时，生活页的“行者之书”标题、阅读器及文章页入口都不会显示。

PDF 下方的标题优先使用 `_data/travel_albums.yml` 中的 `title`；未配置时用文件名（去掉 `.pdf`，`-`、`_` 显示为空格），按文件路径倒序排列。建议用 `年份-地点.pdf` 命名。

封面单独展示，之后固定按 2–3、4–5 配对，同时展示左右两张 PDF 页面。点击页面左、右两侧或使用方向键翻页，快速连续点击会加速翻页，只保留最近一次待翻页意图，超过 200 毫秒未执行的点击会丢弃，不会在停手后积压翻页，按住页面拖动可折页，松手后完成翻页或回弹，手机也支持拖动。PDF 下方居中显示书名，右侧显示当前页码；输入 PDF 页码后按回车可跳转到对应的双页。页码对应原 PDF，空白页保留。

如需自定义，编辑 `_data/travel_albums.yml`，键为本目录下的相对路径，去掉 `.pdf`（包含子目录）：

```yaml
2026-japan:
  title: 日本旅行手记
  description: 一路拍下的风景和日常。
  pdf_cover: true # false 表示没有独立封面，按 1–2、3–4 配对
```

历史 `/travel/` 和 `/travel/文件名/` 链接会直接跳转到生活页中的相册位置。

PDF 和阅读器依赖随站点静态发布。滚动接近相册时才加载 PDF，并按需读取分段。画布展示以照片阅读为主；如需文本搜索、选择或使用原 PDF 中的链接，可下载后阅读。此目录里的 PDF 会公开可访问。
